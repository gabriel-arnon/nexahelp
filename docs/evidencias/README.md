# Evidências

Este diretório é reservado para armazenar evidências dos testes realizados
com o NexaHelp AI, no formato acadêmico da disciplina.

Sugestões de conteúdo a incluir aqui:

- Prints da página inicial (desktop e mobile).
- Prints do chat com perguntas sugeridas, respostas e fontes clicáveis.
- Prints da base de conhecimento com filtros aplicados.
- Prints do painel de histórico de conversas.
- Vídeos curtos (mp4/gif) demonstrando o fluxo completo.
- Notas de teste com data, cenário, entrada, resultado esperado e obtido.

Nomeie os arquivos de forma descritiva, por exemplo:

```
01-home-desktop.png
02-chat-pergunta-senha.png
03-fonte-aberta.png
04-base-filtro-seguranca.png
05-historico-conversas.png
```
